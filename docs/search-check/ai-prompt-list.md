# AI 검색 점검 프롬프트 목록 (고정)

검색 AI(ChatGPT 검색, Gemini, Perplexity 등)에 같은 질문을 던져
**gangsanjawon.com이 답변의 근거로 인용되는지**와 **답변 내용이 맞는지**를 같은 기준으로 비교하기 위한 목록입니다.

- 노출·인용을 보장하는 목록이 아닙니다. AI 답변은 세션·계정·시점에 따라 달라지므로, 한 번의 결과로 순위를 판단하지 않습니다.
- 가능하면 같은 조건으로 봅니다: 로그인 상태·언어(한국어)·검색 기능이 켜진 모드·개인화 최소화. 결과에는 날짜와 도구 이름을 꼭 적습니다.
- 결과 기록은 `ai-YYYY-MM-DD.json` 으로 남기고, 아래 표를 복사해 채웁니다.

## 4. 결과를 사이트에 반영하는 순서

1. 인용되지 않는 질문을 고른다.
2. 그 질문이 기대하는 지역·품목 페이지에 답이 **본문 텍스트로** 있는지 확인한다(이미지·아코디언 안만 있으면 부족).
3. 없으면 `src/region_copy_*.py`(지역) 또는 `src/content.py`·`src/topic_qa.py`(품목·서비스)에 사실만 보충한다.
4. 답이 있는데도 인용되지 않으면 페이지 제목·첫 문단·구조화 데이터(FAQPage)를 먼저 손본다.
5. 다시 빌드하고 `dist/sitemap.xml`에 URL이 들어갔는지 확인한 뒤 배포한다.
