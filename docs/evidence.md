## 2. 사진에서 추정해 쓰던 표현 정리

| 이전 표현 | 처리 |
|---|---|
| “분해해 반출했습니다”, “해체 수거” (사진만으로 분해 여부 확인 불가) | “수거했습니다”로 변경. 블로그 원문에 분해 기록이 있는 서초·마포 사례만 ‘분해’ 표기 |
| “인원을 맞춰 옮겼습니다”, “집게차로 수거했습니다” (사진 근거 없음) | 삭제 |
| “가장 흔한 작업”, “맡기시는 작업”, “문의가 많은 지역”, “당일 작업도 자주” | 삭제 |
| 지역 특징(랜드마크·아파트 단지·“○○ 문의가 많습니다”) 51개 지역 문단 | 삭제. 지역 페이지는 확인할 조건과 실제 기록 사례로 구성 |
| “대부분 하루 안에 끝납니다” | “작업 기간은 물량·층수·반출 동선에 따라 달라 사진을 보고 안내” |
| “재사용·재활용 가능 여부를 함께 확인” (가치 회수 정책처럼 읽힘) | 삭제. “매입은 하지 않습니다”로 대체 |
| 유품정리 “사진과 영상 통화로 진행” (비대면 정책처럼 읽힘) | “진행 방법은 상담 때 사진을 보며 함께 정함”으로 완화 |

## 3. 표기 위치 기준

- 근거가 있는 강점: 홈 히어로 태그, ‘강산자원에 맡기는 이유’, 회사소개, FACTS 표
- 근거가 생기면 추가할 위치: 회사소개 “하는 일” 아래 “경력과 실적” 단락 (기준일·집계 기준 함께)
- 구조화 데이터(LocalBusiness): 업체명, 전화, 주소, 영업시간(24시간 = 상담 기준), 서비스 지역. 평점·후기·허가 정보 없음
