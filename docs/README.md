# 내부 문서

이 폴더는 홈페이지에 공개되지 않습니다. 홈페이지는 `src/` 의 파일로만 만들어집니다.
(GitHub 저장소를 공개로 두면 이 문서도 GitHub에서는 보일 수 있으니 개인정보는 적지 않습니다.)

| 문서 | 내용 |
|---|---|
| evidence.md | 업체 주장별 근거, 홈페이지 처리, 더 필요한 자료 |
| case-sources.md | 작업사례 자료 조사표와 출처 |
| keyword-map.md | 검색 표현 1,342개 → 대응 페이지 (자동 생성) |
| how-to-add-case.md | 새 현장 상세 기록 추가 방법 |
| measurement.md | 클릭 측정, 상담·예약 기록, 검색 도구 제출 절차, canonical·사이트맵 정책 |
| metrics-checklist.md | 4·8·12주 비교 점검표 |

공개 콘텐츠 파일
- `src/content.py`, `src/content_more.py`: 업체 정보, 서비스, 절차, FAQ
- `src/case_data.py`: 현장 상세 기록 (분류·지역·게시일·수정일 포함)
- `src/region_info.py`: 지역별 공식 안내(출처·확인일), 확인 조건, 지역 FAQ, 인근 지역
- `src/topic_qa.py`: 질문형으로 다시 쓴 칼럼·품목 본문
